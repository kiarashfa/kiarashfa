### 🧬 I'm Kia

<img align="right" width="300" src="https://raw.githubusercontent.com/kiarashfa/kiarashfa/main/assets/anim-3-ml-pipeline.svg" alt="A molecule feeding a neural network that predicts a material property"/>

I live a bit of a double life. By day I'm a scientist bringing machine learning to the polymer world, the kind of work that runs on Python, lab data, papers, and conference talks. After hours I switch into builder mode and make the things I wish existed: small, free, open-source web apps, created for the pure joy of building and the habit of always learning something new, with no roadmap and nothing expected in return.

<br/>
<br/>

<img align="left" width="300" src="https://raw.githubusercontent.com/kiarashfa/kiarashfa/main/assets/anim-2-molecular-gnn.svg" alt="A molecule feeding a neural network that predicts a material property"/>

&nbsp;&nbsp;🎓 &nbsp;**Ph.D. in Polymer Science &amp; Engineering**, POLYMAT (UPV/EHU)  
&nbsp;&nbsp;🔬 &nbsp;Machine learning for polymer reaction engineering (emulsion polymerization)  
&nbsp;&nbsp;🐍 &nbsp;Python for modeling, simulation, and data across chemistry and materials  
&nbsp;&nbsp;💻 &nbsp;Free, open-source web apps, built purely for the craft
